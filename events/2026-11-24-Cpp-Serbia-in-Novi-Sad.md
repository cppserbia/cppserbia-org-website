## 🎤 The Talk: The Algebra Behind Great C++ APIs

`std::chrono` is widely called a masterpiece of API design. But why? The secret isn't `constexpr` or templates. It's mathematics.

Add a duration to a time point, and you get a time point. Subtract two time points, and you get a duration. Add two time points, and the code won't compile! That is no accident. It follows a centuries-old mathematical structure, enforced by the type system. Once you learn to see it, you start noticing it everywhere: in raw pointers, in money, even in a Git rebase.

The talk breaks down what makes `<chrono>` so hard to misuse and so easy to extend, and looks for ways to apply the same idea outside the standard library. The goal is to build intuition for API design and bring mathematical concepts to your own domain types, for a safer codebase.

**No mathematical background required.** Just bring the C++ APIs you wish were harder to get wrong.

This is a pre-conference preview of the [Meeting C++ 2026 talk](https://meetingcpp.com/2026/Talks/items/The_Algebra_Behind_Great_Cpp_APIs.html), so you'll see it here first, and your questions and feedback will help shape the final version.
